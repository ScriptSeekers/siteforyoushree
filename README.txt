EXAM PREP DASHBOARD

Files:
- index.html: the website interface
- data.js: syllabus, exam dates and study-plan data
- app.js: interactions, progress tracking, localStorage save, import/export

How to use:
1. Extract this ZIP.
2. Open index.html in a modern browser (Chrome, Safari, Edge or Firefox).
3. Go to Syllabus Tracker and tick a chapter only after you can solve/explain it independently.
4. Progress auto-saves in that browser on that device.
5. Use Export backup to download a JSON backup. Import backup restores it later.

Important:
- Browser localStorage is not the same as saving into a server or syncing across devices.
- Clearing browser site data, using private browsing, or switching devices can remove/separate progress. Export backups regularly.
- To change syllabus or study dates, edit data.js.
- Language chapter placeholders need to be replaced with the actual Hindi/Marathi/French syllabus.
